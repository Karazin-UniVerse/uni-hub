# UniHub — Студентський портал та Е-Деканат ХНУ імені В. Н. Каразіна

Модульний веб-інтерфейс Студентського кабінету та Е-деканату для студентів ХНУ імені В. Н. Каразіна (ННІ комп'ютерних наук та штучного інтелекту).

## 🚀 Стек технологій
- **React 19** + **TypeScript 5.7+**
- **Vite 8**
- **Tailwind CSS v4** + Karazin UniVerse Design Tokens
- **Lucide React** (семантичні векторні іконки)
- **qrcode.react** (генерація QR-кодів стандарту НБУ для мобільного банкінгу)

## 📦 Встановлення та запуск
```bash
# Встановлення залежностей
pnpm install

# Запуск dev-сервера
pnpm run dev

# Збірка продакшн бандла
pnpm run build

# Форматування коду
pnpm run format
```

## 🏛️ Ключові розділи
1. **Головна (Дашборд):** Статус успішності, середній бал (GPA 93.4), гарячі дедлайни Moodle, віджет активної пари з переходом до Zoom.
2. **Оцінки та дисципліни:** Інтерактивний селектор дисциплін семестру, динамічна діаграма успішності, зведена відомість контрольних заходів, розрахунок балів ЄКТС.
3. **Розклад занять:** Матриця розкладу (Пн-Пт) з фільтрами за днями та перемикачем чисельник/знаменник.
4. **Оплата та реквізити:** Банківські реквізити університету з копіюванням в 1 клік, генерація QR-коду НБУ для Monobank / Приват24, історія платежів.
5. **Профіль та Е-Деканат:** Офіційні дані наказу та залікової книжки, академічна виписка (Transcript of Records), електронне замовлення довідок з ЕЦП та QR-верифікацією в ЄДЕБО.
